# Bangumi Glass · Android Compose Client

A user-facing Bangumi client showcasing Jetpack Compose, MVVM, Kyant Backdrop liquid glass, OAuth persistence and official Bangumi APIs.

## Pages

- **放送** — official legacy `GET /calendar` weekday calendar, today's works, featured anime
- **季度** — official `GET /v0/subjects` with year, season-start month (Jan/Apr/Jul/Oct), type and ordering
- **发现** — official `POST /v0/search/subjects` with category and sorting, poster grid, pagination
- **收藏** — user collections (watching, wish, watched, paused, dropped); edit collection status, rating and note
- **作品详情** — cover, ratings, descriptions, tags, episodes, cast, related subjects and episode progress editing
- **人物** — person/character pages, collected status actions and related works
- **我的** — user profile, encrypted OAuth session, automatic refresh and personal index management
- **API 实验室** — full official OpenAPI catalog with parameters, request execution, formatted response and structured cards

**All content is loaded from Bangumi; no fake sample anime are built into the application.**
Not every API is represented by a dedicated high-level user screen: specialized and low-use operations remain accessible through the structured API laboratory.

## Tech

- Android Gradle Plugin 8.9.2; Gradle 8.11.1; Kotlin 2.2.21; JDK 17
- Jetpack Compose, Material 3 controls where appropriate, custom frosted components and Kyant's Backdrop 1.0.0
- Coil 2.7 for asynchronous images
- OkHttp for HTTP clients; WorkManager 12-hour background checks; Android Keystore AES-GCM token storage
- minSdk 26; compileSdk/targetSdk 35
- Release: `isMinifyEnabled = true` and `isShrinkResources = true`, signed with **debug testing certificate only**
- No backend required: App Secret is entered locally on the device and never committed to the public source repository.

## Start

1. Open `bangumi-oauth-android` in Android Studio; install JDK 17 and SDK 35.
2. Sync Gradle. Run the app, open **我的**, enter your Bangumi App Secret, and authorize.
3. In Bangumi's developer console, configure redirect URL `bgmoauthdemo://callback`.
4. Use calendar/discovery screens without login; edits and personalized data require OAuth.
5. Source ZIP includes wrapper generated by the GitHub Actions build pipeline.
6. Since every CI run uses a fresh debug-signing certificate, you may need to uninstall the previous APK before installing the newer one. Uninstalling loses saved tokens.

## Production considerations

- Client secrets cannot be kept truly secret in mobile apps. A backend (or a provider-supported PKCE public-client flow) is necessary to harden a production OAuth client.
- Refresh tokens can be revoked/expire; no third-party client can guarantee indefinite login.
- WorkManager tasks are opportunistic; stopped or heavily restricted apps cannot refresh every 12 hours with strict timing.
- The OpenAPI catalog is a snapshot taken at build time. Unsupported or restricted endpoints may return 403/404.
- Each season filter uses the **first month of a quarter**, not a distinct Bangumi "season" endpoint.
- Kyant Backdrop (Apache-2.0): https://github.com/Kyant0/AndroidLiquidGlass . Applied to the bottom navigation rather than every poster card to improve scrolling performance.
- No real-user OAuth/API integration testing was performed in CI, which validates build artifacts but not a logged-in account.
